3.Prototype and Deployment Instructions：
We invite you to experience NudgeeQ firsthand. The high-fidelity prototype is built as a web-based application, designed for flexible deployment on tablets at library desks.

Link: https://nudgeeq.heilomeow.com/

Instructions for How to Deploy and Use It:

Overview:
NudgeeQ is a web-based interactive prototype designed for the Quiet Zone in UQ Library.
The system simulates how seat-based terminals support low-pressure, non-verbal communication between students.
It includes two modes: Admin Mode (for setup) and User Mode (for student interaction).
The following instructions describe how to deploy the system and how users can interact with it.

Admin Mode — Deploy and Set Up the Terminal:
When entering the website for the first time, the system opens in Admin Mode, used to set up the seat terminal’s physical location. (You can use two devices to set up, simulating different seats)
Steps:
Enter Admin Information
On the initial screen, enter the admin’s name or select an existing role.


Select Table and Seat
Choose the corresponding Table and Seat to bind this device to a specific physical location.


Configure Avatar and Signal
Complete the same setup flow as users do:
Choose an Avatar (profile image).
Select a Signal (such as “Available” or “Focused”) to represent the seat status.


Initialise the Device
Click “Initialise Device” to confirm.
This assigns the current terminal as an active seat within the system.


Exit Admin Mode
Click the avatar icon in the top-left corner and select “Leave Table”.
The terminal is now ready for user interaction.

User Mode — For Student Interaction:
After setup, the system enters User Mode, where students can join, express their status, and interact with others.
1. Join Table
Click “Join Table” on the home screen.
Enter your Nickname.
Choose an Avatar and a Mood Status (e.g., “Focused,” “Happy to Help”).
Click “That’s Me” to confirm and display your avatar at the seat.
2. Set Signal
Choose a Signal that shows your current state (e.g., “Quiet Please” or “Available to Help”).
Click “Continue” to finalise setup.
 Your status will now be visible to nearby seats.
3. Seek Help and Contact Others
Click “Seek Help” to open the nearby table layout.
Tap on another user’s avatar to view their signal and status.
- Keyword Search:
You can search for specific help by entering a keyword (e.g., “cable”).
Avatars containing that keyword in their signal will be highlighted and flashing, making them easy to find.
- Contacting Others:
Click the avatar → select “Contact” → type and send a message.
The receiver will get a pop-up notification and can choose “Sorry,” “Ignore,” or “Sure.”
You’ll immediately see their response on your screen.
4. Edit or Leave
In the top-left corner of the “Seek Help” screen, click your avatar to:


Edit Avatar (change your profile image)
Edit Signal (update your current status)
Leave Table (release the seat)


Selecting “Leave Table” resets the terminal for the next user.


Conclusion:
The NudgeeQ prototype demonstrates a complete interactive flow, from Admin setup to User communication and seat release. It illustrates how the system facilitates silent, low-pressure social interaction while preserving the Quiet Zone’s calm atmosphere. Students can express needs, offer help, or signal for quiet without verbal communication, turning silence into connection.
